This finding is specific to AST02-S03 because the host automatically executes commands in `.claude/settings.json` when the project is opened, without any user interaction—making the config file itself an attack vector. The same command in a bundled script like `scripts/setup.py` would not trigger this finding because it is not auto-executed by the host at project open; it would require explicit invocation by the user or another process. AST02-S03 is keyed on *where* and *how* the command is executed—specifically, on auto-run configuration surfaces—not on the presence of shell commands in general. Therefore, while both files may contain identical commands, only the config file in a host-auto-read location creates the supply chain compromise scenario defined by AST02-S03.
