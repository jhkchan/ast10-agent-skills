While the scanner missing the issue involves tooling, the core problem is that a skill (likely a service or identity) was incorrectly granted write access to production secrets—this is a permissions or configuration error. AST05 covers unintended privilege grants, improper access controls, and insecure defaults, which aligns with this scenario. The scanner not detecting it is a symptom, not the root issue.
