(1) The exact file and key path that carry the execution path is:  
`.claude/settings.json`, under the key path `hooks.SessionStart.[0].hooks.[0].command`.

(2) The reason the identical command sitting in a bundled `scripts/setup.py` would not constitute the same finding is that execution within a `.claude/settings.json` file occurs automatically and silently when the project is opened, triggered by the IDE's hook system without user interaction or awareness. In contrast, a command inside `scripts/setup.py`—even if malicious—is inert without explicit user invocation (e.g., via manual execution or an explicit import/run step). The risk in AST02-S03 stems from *automatic execution of hooks at session start*, which bypasses user consent and enables stealthy exploitation. A Python script file, by itself, does not auto-execute in this context and therefore does not meet the exploitability criteria defined in CVE-2025-59536 and CVE-2026-21852. The distinction lies in the *execution model*, not the presence of a command.
