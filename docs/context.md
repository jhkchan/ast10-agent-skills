# Project Context

Canonical domain glossary for `ast10-agent-skills`. Terms below are adopted as-is by
`spec.md`, `plan.md`, and skill packages; new or conflicting terms are proposed as glossary deltas
in a feature's `spec.md` before being appended here at Ship.

## Glossary

- **Universal Skill Format (USF):** the whitepaper's own published, cross-platform-portable
  manifest schema for agent skill packages, covering `deny_write` rules, network policy, shell
  permissions, and signed content hash. This project adopts USF as an external standard defined by
  the source whitepaper; it does not originate the schema.
